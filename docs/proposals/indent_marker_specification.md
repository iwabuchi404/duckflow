# Sym-Ops v3.2 拡張仕様: インデント・マーカー (Indent Marker)

## 1. 背景と目的
LLMはトークナイザーの特性上、連続する空白文字の数を正確に認識・生成することが困難であり、Python等のオフセットに敏感な言語において `IndentationError` を誘発しやすい。本仕様は、不可視な空白を可視な記号に置換することで、生成精度を向上させ、構文破壊を防止することを目的とする。

## 2. 仕様概要
AIが `edit_lines` や `write_file` でコンテンツを生成する際、行頭のインデントを特定の記号（マーカー）で記述することを許可し、システム側でファイル保存直前にこれをスペースに変換する。

### 2.1 採用マーカー
- **記号**: `·` (Middle Dot, U+00B7)
- **変換倍率**: `·` 1つにつき、スペース1つに変換。
- **理由**: 通常のコード内（文字列リテラルやコメント内を除く）に単独で出現する確率が極めて低く、かつ視覚的に「点」として認識しやすいため。

## 3. 変換ルール（システムの責務）
システム（Tool Executor）は、コンテンツブロック `<<< >>>` から取得した文字列に対して、以下の正規表現による変換を適用した後にファイルへ書き込む。
