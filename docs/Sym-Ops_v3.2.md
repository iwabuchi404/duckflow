# Sym-Ops v3.2: 安定・安全・自己検証版

## 概要
Sym-Ops v3.2 は、**思考** と **アクション** を明確に分離し、自己検証チェックリストと Vitals を必須化した次世代オーケストレーションフォーマットです。  
- `>>` … 思考・推論ブロック（コード外）  
- `::` … アクションマーカー（ツール呼び出し）  
- `<<<` / `>>>` … コンテンツブロックの開始・終了（Git コンフリクトマーカーと同一）  
- `::c`, `::s`, `::m`, `::f` … Vitals（信頼性・安全性・記憶度・焦点）を数値で示す  

## 1. 基本構文
| 要素 | 記法 | 目的 |
|------|------|------|
| 思考 | `>>` | LLM の内部推論。必ずコードブロック外に置く |
| アクション | `::action @target` | ツール呼び出し。`<<<`/`>>>` で囲むことが多い |
| コンテンツブロック | `<<<` `>>>` | 生データ（コード・テキスト）。衝突が起きにくい |
| Vitals | `::c0.9 ::s1.0 ::m0.1 ::f0.8` | アクション直前に必須。信頼性・安全性・記憶度・焦点を示す |
| 自己検証 | `>> [CHECK] …` | 破壊的操作前に必ず記載し、意図と安全性を明示 |

### 例：ファイル作成
>> 新しいユーティリティ関数を追加する必要がある。

::c1.0 ::s1.0 ::m0.0 ::f1.0
::write_file @utils/helpers.py
def hello(name: str) -> str:
    return f"Hello, {name}!"
